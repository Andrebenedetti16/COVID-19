# COVID-19
1️⃣ Análise de Internações por COVID-19 🦠
📌 Visão Geral
Projeto de análise exploratória dos dados de internações hospitalares causadas por COVID-19 no Brasil, com foco em identificar tendências temporais, distribuição regional e impactos no sistema de saúde.

📊 Objetivos
Analisar o volume de internações ao longo do tempo

Identificar picos e padrões por estado/idade/gênero

Gerar visualizações para informar decisões públicas

🛠️ Tecnologias
Python

Pandas

Seaborn / Plotly

Jupyter Notebook
